# 第 05 课：搜索另一个 User

## 学习成果

已认证的 User 用约定的标识搜索，Qt 显示一个匹配的 User，或显示明确的空结果。

## 教程必须覆盖

- 为 demo 选定一种搜索输入，并在 Qt 端做校验。
- 通过现有分发器新增 TCP 请求和响应处理。
- 经 MySQL manager/DAO 层查询 User。
- 只返回 demo 所需的资料字段。
- 防止搜索到自己时触发「添加好友」动作。

## 验收清单

- [ ] 搜索存在的 User 返回正确的资料。
- [ ] 搜索不存在的 User 显示非错误态的空状态。
- [ ] 非法输入不会打到数据库。
- [ ] 搜索结果只在允许时显示「添加好友」动作。

## 功能实现与接口质量

本课只实现“输入规范化 → 查询 → 结果展示”，查询模块返回值类型集合或明确的空结果，不通过输出参数填充列表和数量。数据库访问使用参数化查询；空结果是正常业务状态，不应伪装成系统错误。
