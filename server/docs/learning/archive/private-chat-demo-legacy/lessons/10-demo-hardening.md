# 第 10 课：加固并彩排 9 月 1 日的 demo

## 学习成果

学习者能独立启动整套服务，跑一次可重复的双客户端演示，从预期的本地故障中恢复，并清晰地讲出架构。

## 教程必须覆盖

- 产出一份简短的启动与停止清单。
- 确认配置是运行时驱动的，演示时不暴露密钥。
- 把误导性日志和笼统的报错替换成分层的具体提示。
- 彩排注册、登录、Friend Request、同意和实时 Text Message 全流程。
- 定稿架构讲解话术和可能的面试追问。
- 诚实标注延后功能，不得把未实现的内容说成已实现。

## 验收清单

- [ ] 按文档命令即可启动整套服务，不需要改源码。
- [ ] 两个新账号或已有账号能走完全流程。
- [ ] Redis、MySQL、HTTP、TCP 和 token 故障可以被区分。
- [ ] UI 一致到足以录一段简短的演示视频。
- [ ] 学习者能脱稿讲出五个核心后端决策。
- [ ] 明确排除离线投递和分布式 ChatServer 的声明。

## 功能实现与接口质量

本课只加固已完成的功能：配置检查、错误分类、资源释放、日志脱敏、重复操作和断线恢复。复查所有公开函数：优先返回值类型结果，使用 RAII 管理连接和缓冲区，不新增 `int&`、裸指针或隐式全局状态。每项加固都要有一个可复现的失败验收，不以“程序没崩”作为唯一质量标准。
