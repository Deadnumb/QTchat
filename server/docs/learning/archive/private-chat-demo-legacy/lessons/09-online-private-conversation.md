# 第 09 课：在线交换已持久化的 Text Messages

## 学习成果

两个在线好友实时交换文本，双端渲染正确的气泡，服务端先持久化再返回成功，会话在首条消息后进入「最近会话」。

## 教程必须覆盖

- 定义稳定的客户端和服务端消息标识，支持重试和去重。
- 校验认证、Friendship、会话成员身份和正文长度。
- 向发送方返回成功之前先插入 Text Message。
- 把已存储的消息推送给在线接收方的 Session。
- 用标准 Qt 组件和 QSS 渲染收发两侧气泡。
- 用最后一条消息新增或更新 Recent Conversation 条目。
- 处理数据库或接收方断开等错误时不得谎报已送达。

## 验收清单

- [ ] A 向 B 发送中文和 ASCII 文本。
- [ ] MySQL 中恰好存在一条已存储的 Text Message。
- [ ] A 只在持久化之后看到发送成功。
- [ ] 在线的 B 立即收到并渲染同一条消息。
- [ ] 会话在首条消息时出现在「最近会话」，之后持续更新。
- [ ] 非好友无法向该会话发送消息。

## 功能实现与接口质量

本课顺序是权限校验 → 消息持久化 → 在线转发 → 双端渲染。发送函数返回 `SendMessageResult`，包含消息 ID、状态和必要的展示数据；不要用 `bool + int& message_id`。只有数据库提交成功后才通知发送方成功，转发失败不能伪装成持久化失败。
